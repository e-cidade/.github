# e-Cidade

O **e-Cidade** é um software livre de gestão pública municipal criado
originalmente pela **DBSeller** e desenvolvido ao longo do tempo por diferentes
atores do ecossistema.

Esta organização mantém um espaço comunitário para aproximar projetos,
mantenedores, usuários e colaboradores.

- [Comunidade e projeto](https://github.com/e-cidade/e-cidade)
- [Repositórios da organização](https://github.com/orgs/e-cidade/repositories)

Informações sobre participação, diferentes linhas de desenvolvimento,
governança e transferência de projetos são mantidas no repositório comunitário
[`e-cidade/e-cidade`](https://github.com/e-cidade/e-cidade).
